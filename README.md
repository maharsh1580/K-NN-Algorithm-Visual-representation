🧠 KNN Machine Learning Model in Python

This project implements the K-Nearest Neighbors (KNN) algorithm for classification using Python. The program allows users to select the number of neighbors (K), calculates distances using the Euclidean metric, predicts the class through majority voting, and visualizes the results using Matplotlib.

🚀 Features

Implementation of KNN from scratch

User-defined value of K

Euclidean distance calculation

Data classification using majority voting

Data visualization with Matplotlib

Simple and beginner-friendly code

🛠️ Technologies Used

Python

NumPy

Matplotlib
